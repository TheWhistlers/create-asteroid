# Asteroid

![ICON](./public/avatar.svg)

A simple static personal blog site generator designed to help beginners to build their own site with modern-UI.

## Features

**Simple** | **Pure Markdown** | **Use out of the box**

- Run just a few commands to create your site.
- Focus seperated entirely, bloggers only need to pay their attentions to writing blogs in Markdown.
- Lightweight and easy to use, no dramatic configurations to set, completely used out of box.

## Quick Start

- Please confirm Node.js was installed on your computer before. ( Node.js >= 24 )

  Run command `pnpm create asteroid` to start with a CLI and then input information about your project and select your favorite theme. There are a few presets for you to use, and also, cutomized theme was allow for sure.
- Run `pnpm run dev` to start a server with Vite to test your site
- Just focus on your blogs in markdown, you don't need to care about the style or configurations.
